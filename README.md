# Text to PDF Converter

This is a simple web application built with Flask that allows users to convert text files (.txt) to PDF format.

## Features

- Convert text files (.txt) to PDF format.
- Responsive design for desktop and mobile devices.
- Feedback messages for file upload and conversion.

## Download and Installation (Windows)

To run the application locally on your Windows machine, follow these steps:

1. Download the project zip file from the https://github.com/SHubhamanjk/Text-To-Pdf-Converter 

2. Extract the contents of the zip file to a folder on your computer.

3. Open extract folder and open this folder with vs code:

4. Create a virtual environment (optional but recommended):

         Code : python -m venv venv

5. Activate the virtual environment:

       Code : venv\Scripts\activate

6. Install the required dependencies:

       Code : pip install -r requirements.txt

7. Run the Flask application:

    Open Terminal Of VS Code any write this code there :

        Code : Python app.py
      
8. Open your web browser and navigate to [http://localhost:5000](http://localhost:5000) to access the application.

## Dependencies

The application relies on the following Python packages:

- Flask: Web framework for building the application.
- ReportLab: Library for generating PDF files.
- Other dependencies listed in `requirements.txt`.
